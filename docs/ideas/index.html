Alarma de Diario

Sistema de validación de entrada y procesamiento de imágenes que detecta si llegó el diario y reconoce rostros en la escena, con notificaciones automáticas.

OpenCV NumPy YOLO n8n pytest

¿Qué hace?

Un vistazo rápido al proyecto

¿Qué hace?

Detecta si el diario llegó comparando una foto de referencia (sin diario) contra una foto actual, y reconoce presencia de rostros en la escena.

¿Cómo lo hace?

Procesamiento de imágenes con OpenCV y NumPy para la diferencia de fondo, y un modelo YOLO para la detección facial.

¿Para qué sirve?

Automatiza un aviso vía n8n cuando se valida el evento, sin depender de que alguien esté mirando la cámara.
