# Alarmadediario
Detector de diario en puerta con open CV y numpy
Sistema de detección y monitoreo de imágenes con arquitectura modular, **Test Harness automatizado**, integración con **n8n** y soporte para **Agentes de IA**.

---

## 🚀 Inicio Rápido para Colaboradores

### 1. Clonar el repositorio e instalar entorno
```bash
# Clonar repositorio
git clone https://github.com/RubenArielArguello-ai/Alarmadediario.git
cd Alarmadediario

# (Opcional) Crear y activar entorno virtual
python3 -m venv venv
source venv/bin/activate  # En Windows: venv\Scripts\activate

# Instalar dependencias
pip install -r requirements.txt
