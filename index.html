ALARMA DE DIARIO

"El diario llegó." — dicho por una cámara, no por tu vecino.

Última edición · Detección en tiempo real

Un sistema que sabe cuándo el diario está en tu puerta, antes que vos.

AlarmaDeDiario usa visión artificial para detectar cuándo el diario es depositado en la puerta de tu casa, y te avisa al instante — sin que tengas que salir a mirar cada cinco minutos.

Cómo funciona

01

Captura

La cámara fotografía la zona de la puerta a intervalos regulares.

02

Procesamiento

NumPy y OpenCV analizan la imagen buscando la forma del diario.

03

Clasificación

El sistema decide: ¿hay diario en la escena o no?

04

Alarma

Si se detecta, se dispara la notificación y se guarda la evidencia.

02

Funcionalidades destacadas

Detección

Reconocimiento visual del diario

Combina OpenCV y NumPy para diferenciar el diario del fondo, sin importar la posición exacta en la puerta.

Evidencia

Registro fotográfico automático

Cada detección guarda una imagen marcada, como prueba de que el sistema funcionó correctamente.

Testing

Harness de evaluación automática

Un conjunto de imágenes de prueba permite medir la precisión del detector antes de cada entrega.

Calidad

Integración continua

GitHub Actions ejecuta tests y linting automáticamente ante cada cambio en el repositorio.
