Observaciones Generales — Alarmadediario

Gestión del proyecto

El proyecto debe mantenerse organizado y documentado durante todo su ciclo de desarrollo.

Se prioriza:

* Mantener el código y la documentación sincronizados.
* Utilizar GitHub como repositorio principal.
* Utilizar integración y automatización para validar los cambios.
* Mantener funcionando el pipeline del proyecto.
* Registrar los cambios importantes mediante commits.
* Evitar incorporar credenciales, tokens o información sensible al repositorio.
* Verificar las funcionalidades antes de integrar cambios a la rama principal.

Automatización

El proyecto cuenta con procesos automatizados para facilitar la evaluación y validación del software. Los cambios deben ser revisados antes de considerarse terminados.

Responsabilidad del Project Manager

El Project Manager debe realizar el seguimiento de las tareas, coordinar los cambios, controlar el estado del proyecto y verificar que las actividades planificadas se completen correctamente.
