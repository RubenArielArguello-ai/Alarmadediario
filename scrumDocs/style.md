Guía de Estilo — Alarmadediario

*Programa simple que pueda generar la función de detección y esta pueda adaptarse a diferentes situaciones basandose en el mismo principio de deteccion.

Convenciones de código

* Utilizar Python siguiendo una estructura clara y modular.
* Utilizar nombres descriptivos para variables, funciones y archivos.
* Mantener funciones pequeñas y con una responsabilidad definida.
* Utilizar comentarios únicamente cuando aporten información relevante.
* Mantener una indentación consistente de 4 espacios.

Estructura del proyecto

* Mantener separada la lógica de detección, evaluación, documentación y automatización.
* No incorporar archivos temporales, credenciales ni tokens al repositorio.
* Mantener la documentación actualizada cuando se incorporen cambios importantes.

Git y GitHub

* Utilizar main como rama principal.
* Realizar cambios mediante ramas de trabajo cuando corresponda.
* Utilizar mensajes de commit claros y descriptivos.
* Revisar los cambios antes de realizar un Pull Request.

Calidad

* Verificar que los cambios no rompan la funcionalidad existente.
* Ejecutar las evaluaciones y validaciones automatizadas disponibles.
* Mantener el pipeline de integración continua funcionando correctamente.
